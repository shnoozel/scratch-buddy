# Scratch Buddy

A pocket scratch deck for the phone browser: drag the vinyl, cut with the fader, scratch over a beat, record takes.

- Turn the phone sideways for two-thumb mode (fader on one edge, record on the other; **⇆ Swap** flips sides).
- **Open files…** loads your own samples (mp3 / wav / m4a). **● Mic** records a sample from the microphone.
- **Low cut** removes everything below 100 Hz on the record.
- Recorder: **Everything** (scratch + beat) or **Scratch only**.
- iPhone: flip the silent switch off, or there is no sound.

## Files
- `scratch.html` — the source (also published as a Claude artifact).
- `build.sh` — wraps it into `index.html`, the standalone page GitHub Pages serves.
